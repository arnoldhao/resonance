# 共振涨跌榜 · movement-1.1

涨跌榜统计当日综合 Top 100 相对昨日最后一期综合榜的名次变化，在“共振综合榜”之后提供“共振涨跌榜”入口。

```text
变化名次 = 昨日综合名次 − 今日综合名次
```

- 上升、下降分别按变化幅度绝对值降序排列。
- 同幅度按今日综合名次升序，再按稳定歌曲 ID 升序。
- 首次入榜：昨日不在 Top 100，增量索引中此前也没有进入本榜的记录，按今日综合名次排列。
- 重返榜单：昨日不在 Top 100，但更早曾入榜，另列并按今日综合名次排列。两类的 `delta/previousRank` 均为 `null`，不虚构昨日名次或上升幅度。
- 持平歌曲不进入上升、下降列表；`unchangedCount` 记录其数量。

歌曲的 `rank` 保留今日综合名次，`movementRank` 是该分类中的排序位置，`delta/previousRank/combinedMovement` 沿用综合日榜数据。筛选平台、搜索和导出时保留分类排名。

前一自然日有同一数据模式的已发布日榜即可计算涨跌，直接比较两天的已发布名次。采集范围扩展或计算记录的版本变化不会清空涨跌。没有昨日榜时四个分类列表均为空，`comparisonDate` 为 `null`。含历史沿用时披露 `coverage.comparisonUsesCache`。

日内榜单会更新，但比较基准始终是昨日最后一期，不与当天上一次采样比较，也不累计多次涨跌。榜期滚动、平台刷新不同步和 Apple RSS 日内变化都可能改变当日综合名次；这不是新增的采样权重。

本榜观察范围是今日综合 Top 100，不给跌出 Top 100 的歌曲假定第 101 名，也不据此计算下降幅度。综合涨跌与平台原榜涨跌独立；平台官方的上期可能是上周。

## 周榜与月榜

周榜、月榜页面各提供“共振综合榜 / 共振涨跌榜”切换，以及上升、下降、首次入榜、重返榜单分类。周涨跌使用已有的 `weeklyMovement`，月涨跌使用 `monthlyMovement`；分别比较相邻两个完整周、完整自然月的已发布名次，采集范围扩大不重置比较。

上升、下降按变化幅度绝对值降序，同幅度按本期综合名次升序；首次入榜、重返榜单分别按本期综合名次排列。幅度排名独立显示，原综合名次与上期名次同时保留。分类支持周期选择、搜索、分页和歌曲详情；搜索不改变分类的原幅度排名。

本期预览、日期不完整或缺少相邻完整上期时，页面说明原因，不生成涨跌数据。之后正常构建得到可比较的周期数据，页面即可自动展示；持平歌曲仍保留在综合榜。下载当期周／月 JSON 可读取所有歌曲及涨跌字段，无需额外采集。

按日期查询、JSON 下载与 CSV 导出见 [API 文档](api.md)。

首次与重返只在各自榜单的记录范围内判断；日榜上过榜不等于进入过周榜或月榜。各期 JSON 保存 `entryHistoryStart` 和变化对象中的 `firstEntryDate`，具体索引规则见[日榜方法](methodology.md#涨跌与历史)。
